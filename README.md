# Student & Course Management System

## 1. Project Purpose
A lightweight, modern Single Page Application (SPA) designed for educational labs to efficiently manage student records and course catalogs with zero external backend or database dependencies.

## 2. Technologies Used
* **Frontend Framework:** React 18 (JavaScript ES6+)
* **Build Tool:** Vite
* **Styling & UI:** Bootstrap 5
* **Data Persistence:** Browser `localStorage` API

## 3. Prerequisites
Ensure you have the following installed on your machine:
* [Node.js](https://nodejs.org/) (v16 or higher recommended)
* A modern web browser (Chrome, Firefox, Edge, or Safari)

## 4. Installation Steps
1. Download or clone the project repository.
2. Open your terminal inside the project root folder (`student-lab`).
3. Install the required dependencies by running:
